# VantaBit 🛡️

**Secure, Client-Side Encryption Vault.**
A premium, glass-morphism styled encryption tool built for macOS and Android.

> **VantaBit** is a premium, client-side encryption tool designed for secure file protection. Built with React and Electron, it features a glass-morphism interface and military-grade AES-256 encryption. It operates entirely offline, ensuring zero-knowledge security for your data on macOS and Android.

## ✨ Key Highlights

*   🔒 **Secure**: AES-256 encryption logic runs locally (Offline).
*   💎 **Premium UI**: Titanium/Glass aesthetic with fluid animations.
*   🍎 **Native macOS**: Standalone `.dmg` application.
*   🎓 **Educational**: Created by KenKolder / PRAJWAL VP for learning purposes.

## 🚀 Installation

### macOS (Desktop)
1.  Go to the **[Releases](../../releases)** page.
2.  Download `VantaBit.dmg`.
3.  Drag "VantaBit" to your Applications folder.
4.  Launch the app!

## 🛠️ Development

### Prerequisites
*   Node.js (v18+)
*   npm

### Setup
```bash
# Clone the repository
git clone https://github.com/KenKolder/VantaBit.git
cd VantaBit

# Install dependencies
npm install

# Run web version locally
npm run dev
```

### Build Native Apps

**macOS:**
```bash
npm run dist
```
*Output: `dist/VantaBit-1.0.0-arm64.dmg`*
